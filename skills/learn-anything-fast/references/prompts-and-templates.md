# Prompts and templates

Load only the sections needed for the active mode.

## Learning roadmap

```markdown
# Learning contract
- Topic:
- Target performance:
- Current level:
- Time budget and deadline:
- Final evidence:
- Assumptions:

## Level ladder
| Level | Can do | Learn next | Practice | Common errors | Advancement gate |
|---|---|---|---|---|---|

## Core 20 percent
| Priority | Concept or skill | Why it has leverage | Treatment |
|---|---|---|---|

## Schedule
| Block | Focus | Retrieval task | Deliverable | Gate |
|---|---|---|---|---|
```

Use `Treatment` values `learn now`, `recognize`, or `defer`.

## Quiz state

```markdown
### Feedback
- Score: x/y
- Correct:
- Smallest correction:
- Error type: knowledge | reasoning | execution | careless

### State
- Current level:
- Mastered:
- Weak:
- Evidence:
- Next target:

### Question
[Exactly one question or task. Do not include the answer.]
```

Use a rubric suited to the task. A default five-point rubric is: correctness 2, reasoning 1, application 1, clarity 1.

## Weakness ledger

```markdown
| Item | Error type | Evidence | Correction | Retest variation | Status |
|---|---|---|---|---|---|
```

Use status values `open`, `retesting`, or `mastered`.

## One-page cheat sheet

```markdown
# [Topic]

## One-sentence definition

## Key concepts

## Concrete examples

## Common errors

## Before-use checklist

## Five self-test questions
```

Compress only material the learner has encountered or the user supplied. Mark facts that still require verification.

## Resource shortlist

```markdown
| Resource | Authority | Difficulty | Best for | Use these parts | Skip | Why it earns time |
|---|---|---|---|---|---|---|
```

Use no more than five resources. Link directly to the source. For current recommendations, verify availability and edition before presenting the shortlist.

## Feynman teach-back review

```markdown
### Correct

### Wrong

### Vague or jargon-hidden

### Missing

### Simpler model

### Retest
[One question targeting the most important weak point.]
```

Do not replace the learner's explanation with a polished lecture. Diagnose it, repair the smallest gap, then ask for another explanation or application.

## Calibration checklist

- Is the claim supported by a primary or official source?
- Is the source current enough for this topic?
- Are fact, consensus, opinion, and inference labeled distinctly?
- Does a real example or artifact behave as the explanation predicts?
- Could the AI and learner be reinforcing the same false assumption?
- What observation would falsify the current understanding?
