# 排障手册

## 退出码对照

| 退出码 | 含义 | 处置 |
| --- | --- | --- |
| 0 | 成功 | 继续看截图核验 |
| 2 | 环境失败：微信主窗口找不到、文件不存在 | 确认微信已登录且窗口未关闭；确认文件路径 |
| 3 | 安全拦截：微信窗口没能置前 | 见下方"窗口置前失败" |
| 4 | @成员选择框未弹出 | 输入框已被清空，什么都没发；见下方说明 |
| 5 | 查询词泄漏进消息输入框 | Ctrl+F 没唤起搜索框，脚本已清空残文并未发送；见下方说明 |
| 6 | 用户正忙，主动让路 | 空闲门控超时。这不是故障；等用户空闲后重跑，或调大 `--wait-idle-max` |

## 查询词掉进了消息输入框（退出码 5）

现象：`s1_search.png` 里搜索框是空的，而**某个会话的输入框里出现了要搜索的名字**。
原因：`Ctrl+F` 没有被微信接收（客户端卡顿、窗口刚恢复、或用户当时正在微信里打字抢焦点）。

脚本的保护：对比 Ctrl+F 前后两张截图的"消息输入框区域"，发现变化就点进输入框、
`Ctrl+A` + `Delete` 清掉残文，然后以退出码 5 中止——**不会发出任何内容**。

处置：
- 确认微信窗口不是刚被最小化还原（还原后多等 1 秒再跑）。
- 确认没有其他程序在前台抢按键。
- 若频繁发生，加大 `--config` 里的 `ui_wait` / `search_wait`，并联调时加上 `--require-idle`。

## 用户正忙（退出码 6）

`--require-idle` 要求用户连续 N 秒无键鼠输入才动手。用户一直在用电脑时，
等待到 `--wait-idle-max` 上限就放弃，**不抢窗口、不发送**。
定时任务可据此选择"稍后重试"，不要为了准点而打断用户。

## 窗口置前失败（退出码 3）

脚本已内置四重兜底（Alt 轻敲、最小化+还原、TOPMOST 闪烁、AttachThreadInput）。
仍然失败通常是：

- 微信被最小化到托盘：先手动点开微信窗口，再运行。
- 前台有全屏应用或 UAC 提示框抢占：关掉后重试。
- 远程桌面断开后前台被锁：保持本地会话活跃。
- 被安全软件拦截合成按键：把 .venv 里的 python.exe 加入白名单。

## 点不到输入框 / 点击位置偏移

输入框位置按窗口比例计算，默认 `[0.68, 0.82]`。若微信改版或窗口被拉伸：

1. 手工截一张微信窗口图，量出输入框中心的相对位置（x/宽, y/高）。
2. 写一个 JSON 配置并用 `--config` 传入：

```json
{
  "input_xy": [0.68, 0.80],
  "picker_box": [0.28, 0.42, 0.58, 0.80],
  "picker_min_changed_pixels": 1500,
  "ui_wait": 1.2,
  "search_wait": 1.6
}
```

另外注意系统 DPI 缩放：100% 缩放下点击最准；125%/150% 缩放时窗口 rect 是逻辑像素而
截图是物理像素，脚本已按屏幕宽度比例做了换算，但仍建议先跑一次 prepare 看截图确认。

## @成员选择框没弹出（退出码 4）

- 确认 `--chat` 指向的是**群聊**，单聊没有成员选择框。
- 确认当前账号在该群有 @所有人 权限（非群主/管理员在部分群会没有"所有人"项）。
- 粘贴 `@` 后选择框通常立刻弹出；若网络或客户端卡顿，可加大 `ui_wait` 后重试。
- 脚本在判定未弹出时会先清空输入框，所以不会误发 `@`。

## @错了人

`--mention-name` 会先在选择框里过滤再回车选中**第一项**。若同名成员较多，第一项可能不是
目标。务必在 `s3b_prepared.png` 里确认提及的是正确的人，不对就 abort 重来。

## 发到了错误的聊天

说明 `--chat` 没能唯一命中，或搜索结果首位不是目标。措施：

- `--chat` 使用完整、唯一的名称（可带后缀特征，例如群名自带的后缀/版本号，避免命中同名群）。
- prepare 后必须看图确认聊天标题，再做 send。
- 已误发时：在微信里手动撤回（2 分钟内可撤回），并向用户如实报告。

## 消息内容与预期不一致

- 粘贴内容里的换行不会触发发送，`s3_prepared.png` 里应能看到完整多行文本。
- Emoji 以 Unicode 字符粘贴，会正常显示为表情；若目标机器字体缺失则显示为方块。
- 文字里出现 `\n` 字面量：说明用了 `--text` 但没被转义，检查是否写成 `\\n`。

## 与定时任务配合

- 定时任务每次运行都是新会话，prompt 里必须写全绝对路径（脚本路径、内容文件、截图目录）。
- 建议每次运行前 `os.makedirs(outdir, exist_ok=True)`（脚本已自动创建）。
- 日志与历史文件（例如"用过的文案"）不要写在临时目录以外的位置，避免清理时丢失。
