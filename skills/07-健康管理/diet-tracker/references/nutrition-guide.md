# 营养估算参考（Nutrition Guide）

本文件提供食物营养速查与估算法，供估算用户报餐时查阅。所有数值为**估算基准**（约值），有营养成分表实拍时以实物标签为准。

## 估算方法要点

1. **可食部原则**：骨头、壳、肥肉丢弃部分不计。例：鸭脖 80g 可食部约 50g。
2. **烹调油记账**：中餐最大的隐性脂肪来源。
   - 清炒/凉拌：8~10g 油/份
   - 重油菜（湘菜/川菜小炒、干锅）：15~20g 油/份
   - 油炸/煎炸（金钱蛋、豆腐串、炸鸡）：另计 10~15g
   - 芝麻酱/花生酱（热干面等）：18~20g/大勺
3. **复合菜拆分**：按"主料可食部 + 配菜 + 油 + 酱料"分别估后相加。
4. **不确定就标 ≈**：给量级不给假精确。用户纠正（如"那是梅干菜炒五花肉不是木耳炒肉片"）立即重算。
5. **液体水分**：ml 直接计入水分；咖啡可打 8 折记（利尿）；无糖饮料计水分、0 营养。

## 关键营养直觉（速记）

- 蛋：~6.5g 蛋白/个；奶：~3.2g 蛋白/100ml；瘦肉：~20g 蛋白/100g
- 肉 100g 日限额（尿酸人群）；全脂奶每天 2 盒 ≈ 18~21g 脂肪（换脱脂砍掉大半）
- 纤维要凑够 25g 很难全靠菜：奇亚籽/坚果/豆类密度远高于蔬菜
- 蔬菜九成是水，"100g 西兰花"纤维只有 2.6g，别高估
