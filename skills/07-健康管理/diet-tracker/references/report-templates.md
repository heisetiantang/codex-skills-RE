# 报告模板与渲染规范

本文件定义两类输出：① 周期分析报告（周报/多周报告）的结构；② 带色表格的 HTML 渲染规范。日常报餐只输出"三行结论"，不要套用本文件。

## 一、周期分析报告

### 精简诊断版（推荐，用户"要报告/分析"时默认）

**原则：只讲三件事——做得好 / 做得不好 / 怎么改。绝不堆数据。**

结构：
```
# 饮食分析报告（时间范围）

## 核心判断（一句话）
习惯层的改进是否成功？结构层的短板是否解决？给一个综合达标率(达标格/总格)。

## ✅ 做得好（保持即可）
- 每条给数据支撑（如：水分达标率 82%，从 800ml 起步到稳定 2200ml+）
- 里程碑事件单列（如：脱脂奶切换每天省 20g 脂肪；果味咖啡清零）

## ❌ 做得不好（全部原因，别超过 3 条）
- 纤维：均值 X / 目标 25g，N 天全红 —— 最大差距
- 脂肪：均值 X，超标 N 天 —— 指明超标来源是什么食物
- 蛋白：波动区间，如 ±30g 两极（两餐制日偏低、聚餐日爆表）

## 🔧 怎么改（按优先级 P0/P1/P2，一次只攻一项）
- P0：给出具体可执行动作（每餐绿叶菜 300g + 主食掺粗粮 + 下午奇亚籽酸奶加餐）
- P1：降频类建议（卤味/高脂零食 ≤1 次/周）
- P2：防回潮（空腹超 6 小时先垫杯奶；晚间饿只吃蔬菜蛋）

## 附：统计口径
- 达标线：以账本头部生效基准为准（示例 uric-acid：蛋白65~70g/脂肪≤50g/热量1500~2500kcal/水分2000~2500ml/纤维25~30g）；未初始化按中性默认（蛋白55~75/脂肪≤60/热量1500~2500/水2000~2500/纤维25~30）
- 按有记录天数计均值；注明记录天数
```

### 若用户要"完整版"
在上述基础上增加：逐日趋势表、红线事件时间线（果糖/酒精/卤味/暴食事件）、分周对比。**仍要保持重点突出**，完整版默认折叠为次要内容。

## 二、HTML 渲染规范（带色表格）

Markdown 表格无法表达字体颜色。需要颜色标注时输出自包含 HTML（单文件、内联 CSS），规则：

### 配色（严格三色，全用字体颜色，不用背景色）

| 状态 | 颜色 | 适用 |
|------|------|------|
| 达标 | `#2e7d32`（绿） | 数值落在达标区间 |
| 偏低 | `#c62828`（红） | 低于下限 |
| 超标 | `#8e24aa`（深紫） | 高于上限 |

- **水分 >2500ml 例外：仍标绿**（多喝有益；高尿酸人群尤其鼓励）
- 不使用黄色/橙色（与红绿区分度差）

### 表格结构（周视图）

列顺序：`日期 | 蛋白 | 脂肪 | 热量 | 水分 | 纤维 | 吃了什么(时间)`

```
当周：周一~今天，一天一行
历史周：一周一行，5个营养列取日均值，标注"周均·记N天"（**N≥2 才称周均；仅1天标"仅1天"**）
所有历史周行都列出（不漏行）
```

### 渲染要点

- 页面浅色背景（`#f5f6f8`），正文深色（`#2b2f36`），与亮色 IDE 主题一致
- 表格白底、细边框（`border-bottom:1px solid #eceef0`），列头浅灰底
- 数字列右对齐（`tabular-nums`）
- "吃了什么"列不写饮水；内容长用分号紧凑罗列；餐次用 `<br>` 或分号分隔
- 表头下方给一行说明：颜色含义（绿=达标 红=偏低 紫=超标）
- 表后附 ≤3 行结论（✅/⚠️）

### 简易示例

```html
<table>
  <tr><th>日期</th><th>蛋白</th><th>脂肪</th><th>热量</th><th>水分</th><th>纤维</th><th>吃了什么(时间)</th></tr>
  <tr>
    <td>4.20（一）</td>
    <td style="color:#2e7d32">58g</td>
    <td style="color:#8e24aa">63g</td>
    <td style="color:#2e7d32">1510</td>
    <td style="color:#c62828">1350ml</td>
    <td style="color:#c62828">7g</td>
    <td>早08:20：燕麦粥+茶叶蛋+豆浆；午13:00：番茄牛腩饭+时蔬</td>
  </tr>
</table>
```

## 三、周视图纯文本/表格兜底

若无法输出 HTML（聊天环境限制），用 Markdown 表并在表下注明"颜色规则：绿=达标/红=偏低/紫=超标，本表以文字标注代替"——在异常数值后加 `(紫)` `(红)` 角标。

## 四、报告频率建议

- **日**：三行结论（每次报餐后）
- **周**：每周一可对上周出一次周小结（用户要求时才主动出）
- **月/季**：完整版分析
- 用户说"太复杂/重点不突出" → 立即收敛到精简诊断版
