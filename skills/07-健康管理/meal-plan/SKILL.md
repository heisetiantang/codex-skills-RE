# 减脂配餐

**先算数，再配餐。** 不算热量就减脂，等于蒙着眼睛开车 —— 前两周可能掉秤，第三周必反弹。

## 触发条件

**第一类 · 要方案**（用户给体重 / 身高 / 目标）：

「怎么吃能瘦」「减脂餐怎么配」「每天该吃多少卡」「帮我配个餐」「减脂食谱给我一份」

**第二类 · 点餐求助**：

「点外卖怎么选」「外卖怎么点不胖」「轻食沙拉能吃吗」「火锅怎么吃」「早餐吃什么」

**第三类 · 场景应对**：

「应酬怎么办」「饭局怎么控制」「聚餐前要做什么」「喝酒会不会胖」「出差怎么吃」

**第四类 · 卡住了**：

「体重卡住不掉了」「平台期怎么突破」「吃很少还是不瘦」「是不是要吃更少」

## 核心工作流（4 步）

### 第 1 步：三个数先算出来

**每日摄入目标**（用脚本算，禁止心算）：

```
基础档 = 体重(kg) × 25～30     （久坐取 25，活动多取 30）
减脂档 = 基础档 × 0.8
```

| 参数 | 目标值 | 为什么 |
|---|---|---|
| 每日热量 | 见上式 | 先按此执行 **2 周**，再校准 |
| **蛋白质** | **1.6 g/kg 体重** | 保肌肉 = 保代谢 = 不反弹的**核心** |
| 减脂速度 | 每周降 **0.5–1%** 体重 | 快于此 = 吃太少会反弹；慢于此 = 再减 100 kcal |

**校准规则**（2 周后）：
- 掉秤快于 1%/周 → 加 100 kcal（当前吃太狠）
- 掉秤慢于 0.5%/周 → 减 100 kcal
- **每次只调 100 kcal，不要一次砍一半。**

**不需要称重一辈子**：前 2 周称量建立「眼感」，之后用**掌拳法**估算。

### 第 2 步：输出三餐方案（掌拳法）

```
## 你的数字
体重 70kg ｜ 每日热量 ≈ 1,400 kcal ｜ 蛋白质 ≈ 112 g

## 每餐结构（掌拳法）
一掌心蛋白质（鸡胸/鱼/蛋/豆腐/瘦牛肉）
一拳主食（优先粗粮：杂粮饭/燕麦/红薯）
两拳蔬菜（深色为主）
一拇指脂肪（坚果/橄榄油/牛油果）

## 今日示例
早餐（10 分钟内）：鸡蛋 2 个 + 即食燕麦 40g + 无糖豆浆 300ml
午餐（外卖）：麦当劳板烧鸡腿堡 + 零度可乐（去薯条）
晚餐（自己做）：清蒸鱼 150g + 杂粮饭 1 拳 + 西兰花 2 拳
加餐（可选）：无糖酸奶 1 杯 / 水煮蛋 1 个
```

### 第 3 步：外卖白名单（用户最需要的部分）

**优先级**：蒸煮炖烤 > 爆炒 > 油炸

- ⚠️ **轻食沙拉的酱料能让热量翻倍** —— 酱另装，蘸着吃。
- 安全组合示例：
  - 麦当劳：板烧鸡腿堡 + 零度可乐（不要中薯）
  - 麻辣烫：多菜少丸、汤底过水、不加麻酱
  - 黄焖鸡米饭：鸡多饭少、去皮
  - 日料：刺身 / 烤鱼 / 茶碗蒸，避开天妇罗和寿司卷（含糖醋饭）
- **点餐前估热量：正餐控制在 600–700 kcal 内。**

### 第 4 步：应酬与平台期

**应酬**：
- 出门前 1 小时吃个鸡蛋或喝杯蛋白粉**垫底**
- 席间**先夹菜和蛋白，主食最后动**
- 酒选干红 / 清酒小杯控量；**啤酒和含糖鸡尾酒是热量陷阱**

**平台期排查顺序**（按这个顺序，不要跳步）：
1. 先查**隐性热量**（酱料 / 零食 / 饮料 / 坚果抓一把）
2. 睡眠是否不足（睡不够会拉高食欲激素）
3. 是否处于水肿期（女性经期前后、高盐后 2–3 天）
4. 最后才考虑加运动量

**突破顺序：先清零隐性热量 → 再降 100 kcal → 最后加消耗。**

## 备餐策略（决定成败的一步）

- 周末**炖一大锅鸡肉/牛肉 + 蒸一锅杂粮饭**，分装冷冻，工作日热一下配蔬菜。
- 调料是**隐形热量重灾区**：沙拉酱 / 花生酱 / 糖醋汁换成醋、柠檬、低卡酱。
- **奶茶戒法**：全糖 → 七分 → 三分 → 无糖气泡水/美式，**每 2 周降一档**，无痛过渡。

## 红线

- **不做医疗诊断、不开处方、不推荐具体减肥药或代餐产品。**
- 有**糖尿病、肾病、痛风、甲减、孕期哺乳期、进食障碍史** → 明确说明需先咨询医生或临床营养师，不给通用方案。
- **不鼓励极低热量（<1,200 kcal/天）**，不鼓励断食超过 16 小时，不与「7 天瘦 10 斤」类目标合作。
- **不评判体重和身材**，不说「你太胖了」。用户带着羞耻感来，说教一次就永远不回来。
- 未成年人（<18 岁）减脂 → 只讲均衡饮食与运动，不设热量缺口。

## 反模式

- ❌ 直接给一份「减脂食谱」不问体重和目标（方案必然不可用）
- ❌ 只讲「少油少盐多运动」这种零信息量的话
- ❌ 忽略酱料 / 饮料 / 零食等隐性热量
- ❌ 平台期就让人「加大运动量」（先查吃，再谈动）
- ❌ 一次砍 500 kcal（会掉肌肉、掉代谢、必反弹）
