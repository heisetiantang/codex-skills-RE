# SolidWorks 自动化技能

## 快速开始

### 环境要求

- Windows 系统 + SolidWorks 已安装并运行
- Python 3.8+ + `pywin32` / `comtypes`

### 入口自检

```bash
python scripts/sw_preflight.py
```
